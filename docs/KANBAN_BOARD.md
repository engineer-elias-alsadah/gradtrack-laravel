## 📋 أعمدة اللوحة (Kanban Columns)
1. **Backlog (قائمة الأعمال المؤجلة):** المهام المخطط لها مستقبلاً.
2. **Ready / To Do (جاهزة للبدء):** المهام المحددة للمرحلة الحالية.
3. **In Progress (قيد التنفيذ):** مهام يُعمل عليها حالياً في فرع مستقل (`feature/*`).
4. **Review / PR (قيد المراجعة):** فروع مرفوعة في Pull Request وتنتظر الفحص.
5. **Done (مكتملة):** تم دمجها في `main` بعد اجتياز الـ CI والاختبارات.
